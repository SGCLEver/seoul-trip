# Сеул · 22–27 февраля 2027

Карта Сеула, Инчхона и Йонъина, шесть дней групповой программы и личный план. Отель, рейсы, заметки и отметки хранятся в браузере. Их можно перенести через экспорт JSON.

## Предпросмотр

Нужны Node.js 24 и pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm build
pnpm preview --host 127.0.0.1
```

Для проверки скачивания офлайн-пакета открой адрес, который выведет `pnpm preview`. Для разработки с обновлением при изменениях используй `pnpm dev`. Офлайн-пакет собирается командой `pnpm build`.

Чтобы проверить подпуть, помести содержимое `dist` в папку `seoul-trip` внутри корня локального HTTP-сервера. Открой `http://127.0.0.1:4173/seoul-trip/`. Прямые ссылки используют фрагмент адреса, например `#day/4` или `#place/seoul-sky?day=4`. Дата в ссылке на место задаёт часы посещения.

## iPhone

1. Открой ссылку в Safari. В меню «Поделиться» выбери «На экран „Домой“». Включи «Открывать как веб-приложение», если Safari показывает этот пункт.
2. Запусти «Сеул» с экрана «Домой». В настройках нажми «Скачать для офлайна» и дождись отметки «Офлайн готов». Пакет занимает около 12,5 МБ.
3. Включи авиарежим и проверь, что Wi‑Fi отключён. Закрой приложение полностью и открой его снова. Проверь карту, увеличение масштаба и адрес любой точки. Внешним картам и расписаниям нужен интернет.

Если система освободит место и удалит кэш сайта, скачай пакет заново. Перед этим можно сохранить настройки через «Экспорт JSON». [Инструкция Apple](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/27/ios/27)

## Как обновить программу

- `src/trip.ts` содержит порядок остановок, план на свободное время и связи между событиями. Для времени встречи или визита укажи `start` и при необходимости `end` строками `HH:mm` по Сеулу. Для неподтверждённого времени оставь `null`. После обновления измени `PROGRAM_DATE`.
- `src/places.json` хранит названия, адреса, ссылки и координаты в порядке широта, долгота. `src/place-details.json` хранит часы, исключения на конкретные даты, входы и подходы. Сохраняй ID событий и мест при обновлениях: к ним привязаны отметки и переносы.
- Отель и рейсы пользователь добавляет в «Настройках». Например, у отеля можно указать название, корейский адрес, станцию и пару координат. Для рейса можно указать номер, терминал и информацию о встрече. Эти поля не входят в сборку.
- Организатору нужно подтвердить рейсы, терминалы и встречи, отель, площадку и время мастер-класса и NANTA, точку встречи в Ёнсе и возвращение из Йонъина. На даты поездки дополнительно сверяются последние рейсы с Намсана, часы N Gift, календарь деревни, месячные выходные магазинов и специальные часы музеев. Часть карточек содержит обычные часы и ссылки на оператора.

## Свои визиты

В «Плане» нажми «Добавить место». Введи название и выбери точку из подсказок либо оставь это название для нового места. Для нового места можно добавить адрес или поставить точку касанием карты. День обязателен, время и заметка по желанию. В личном плане можно отредактировать визит, перенести его, отметить посещение или убрать из списка. Свои визиты и отметки входят в экспорт JSON. Блок «Сегодня» использует время Сеула и показывает следующий неотмеченный пункт текущего дня.

## Сборы

В разделе «Сборы» можно добавить свой пункт или выбрать готовый из блока «Что проверить до вылета». Свои пункты можно переименовать, отмечать и удалять. Список работает офлайн и входит в резервную копию JSON.

## Подложка

В `map-data/seoul.pmtiles` лежит региональный фрагмент [Protomaps Basemap](https://source.coop/protomaps/openstreetmap) с обзорными уровнями 8–10 для всей поездки, улицами на уровнях 11–12 в Сеуле и у остановок вне города, а также уровнями 13–14 в зонах программы. Версия исходной карты 4, сборка 10.03.2026. Данные © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Указание авторства видно на карте. Границы подробной карты лежат в `map-data/*-areas.geojson`. Если для текущего масштаба тайл за пределами этих зон отсутствует, карта использует ближайший сохранённый уровень. Карта показывает улицы, парки, реку, районы и станции. Указания к месту находятся в карточках и плане.

Для пересборки подложки установи [PMTiles CLI](https://github.com/protomaps/go-pmtiles/releases/tag/v1.31.2) и запусти `bash scripts/prepare-map.sh`. Переменная `SEOUL_OSM_SOURCE` позволяет указать совместимый исходный архив Protomaps. Скрипт работает с исходной выгрузкой, которую можно распространять по лицензии ODbL. При обновлении карты измени дату подложки в README.

Приложение может читать байтовые диапазоны с сервера. Если сервер отдаёт файл целиком, клиент читает диапазоны из локальной копии. После скачивания офлайн-пакета диапазоны обслуживает service worker. Он открывает последнюю сохранённую версию сразу и проверяет наличие обновлений отдельно. Если обновляется программа при прежнем архиве, браузер использует уже сохранённый файл карты. При прерванном обновлении продолжает работать последняя целая версия.

## GitHub Pages

После подтверждения опубликуй код в целевом репозитории и в **Settings → Pages → Source** выбери **GitHub Actions**. Запусти **Actions → Publish Seoul trip to GitHub Pages → Run workflow** на основной ветке. Рабочий процесс запускается вручную. Итоговый URL будет в окружении `github-pages`. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

## Проверено локально

Сборка и типы проходят. Проверка на ширине 360 px выполнена в мобильном профиле iPhone в WebKit и Chromium. Проверены карта и поиск по трём языкам, фильтры, общие маркеры, переход к месту из плана, перенос личного пункта, терминал рейса, отель, заметки, создание своей точки касанием карты, перенос визита, редактирование сборов и резервная копия. В Chromium проверены разрешение и отказ в геолокации.

Офлайн-пакет проверен под подпутём `/seoul-trip/`. В Chromium сеть отключалась через браузер, в WebKit на время полной перезагрузки останавливался HTTP-сервер. В обоих случаях работали карта с приближением, шесть дней программы, адреса и личные отметки. Свои пункты можно было добавить офлайн и сохранить после перезапуска. Для всех 37 точек с координатами подтверждено наличие тайлов с улицами. Иконка с экрана «Домой», переход в установленное приложение NAVER и авиарежим на физическом iPhone требуют проверки после выдачи HTTPS-ссылки.
